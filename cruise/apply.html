Cruise Alpha Tester Application

Cruise is currently in early alpha testing. Anyone willing to try it and give feedback is welcome to apply.

Used to send test invitations, version updates and important security notices.

Testing notes

  • Cruise is experimental software and may contain bugs, compatibility issues or unknown security vulnerabilities.
  • The current test build is not signed with an Apple Developer ID or notarized by Apple. macOS may require you to manually approve it before it runs.
  • Do not use Cruise as your only or main browser, and avoid important accounts or sensitive data during testing.
  • Back up important data beforehand. If you run into problems, you can stop using Cruise at any time and contact the developer.
  • Cruise may store browsing history, cookies and other data on your Mac, as normal browsing requires, but no information will be sent to the developer.
